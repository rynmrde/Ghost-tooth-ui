# راهنمای سریع — Ghost Tooth UI

> ترجمه‌ی خلاصه‌ی README; جزئیات فنی در [`INTEGRATION.md`](INTEGRATION.md) (انگلیسی).

## این چیست؟

یک پیلود برای PS5 که تب **Media** کنسول یک کاشی به نام **Ghost Tooth** اضافه
می‌کند. بازش که می‌کنی، یک صفحه‌ی ساده می‌بینید که:

1. دستگاه‌های بلوتوث اطراف را نشان می‌دهد (اسکن),
2. هندزفری مورد نظر را انتخاب می‌کنید,
3. آدرس آن را در `headset.ini` می‌نویسد و `ghost-toothAPI` را دوباره اجرا
   می‌کند تا دقیقاً همان دستگاه را وصل کند.

هیچ تغییری در `ghost-toothAPI.elf` داده نمی‌شود — نه پچ، نه ری‌بیلد. این فقط
همان فایل‌ها را می‌خواند و می‌نویسد که خودِ پیلود استفاده می‌کند.

## نصب

1. فایل `ghost-tooth-ui.elf` را از Releases بگیرید.
2. مطمئن شوید `ghost-toothAPI.elf` در `/data/ghost-toothAPI/` هست (اگر نیست،
   این پیلود نسخه‌ی داخل خودش را آنجا می‌گذارد).
3. یک بار `ghost-tooth-ui.elf` را با لودر همیشگی‌تان اجرا کنید.
4. پیامی روی صفحه می‌آید: کاشی ثبت شد. از این بعد لازم نیست پیلود را با لودر
   اجرا کنید — تا ری‌بوت بعدی.
5. بروید به Home → تب **Media** → کاشی **Ghost Tooth**.

## وصل شدن به هندزفری

* هندزفری را **حالت pairing** بگذارید (معمولاً ۵ ثانیه نگه‌داشتن دکمه‌ی پاور).
* دکمه‌ی **Scan for devices** را بزنید (یا دکمه‌ی **△**).
  حدود ۱۶ ثانیه طول می‌کشد — این همان مرحله‌ی جست‌وجوی خودِ پیلود است.
* روی کارتِ هندزفری مورد نظر **Connect** را بزنید (یا **✕**).
* در بخش Status باید این را ببینید: `streaming` + `SBC 48000 Hz`.
  صدای بازی حالا از هندزفری می‌آید.

اگر لیست خالی بود، آدرس را دستی وارد کنید — هر آدرسی که در لاگ پایین صفحه
هست کار می‌کند، حتی اگر در لیست نباشد.

## دکمه‌ها

| کار | نتیجه |
| --- | --- |
| **Restart payload** | ghost-toothAPI را با تنظیمات فعلی دوباره اجرا می‌کند |
| **Stop payload** | آن را می‌بندد (اگر کرنل اجازه نداد، هندزفری را خاموش کنید) |
| **Let it pick** | انتخاب خودکار؛ `headset.ini` را از پین خالی می‌کند |
| **Forget pairing** | `bond.key` و `peer.name` پاک می‌شوند — برای وقتی هندزفری را عوض می‌کنید |

با کنترلر: جهت‌نما برای جابه‌جایی، **✕** برای انتخاب، **△** برای اسکن،
**○** برای توقف پیلود.

## حذف کاشی

```sh
# با لودر:
ghost-tooth-ui.elf --uninstall-tile
```

## نکات

* **اسکن، همان اسکنِ خودِ پیلود است.** حالت «فقط جست‌وجو» در ghost-toothAPI وجود
  ندارد؛ برای همین هنگام اسکن یک آدرس بی‌پاسخ (`02:00:00:00:00:00`) موقتاً پین
  می‌شود تا پیلود به هیچ دستگاهی وصل نشود، و بعد از اسکن تنظیمات قبلی شما
  برگردانده می‌شود.
* اگر دستگاهی بی‌نام دیده شد، اسمش `ghost-tooth AA:BB` است — آدرس واقعی است،
  نام نه.
* صفحه در شبکه‌ی داخلی هم باز می‌شود: `http://<ip-ps5>:8899/` (مثلاً با
  موبایل)، برای تایپ کردن آدرس راحت‌تر است.

## گرفتن فایل ELF (خروجی این نسخه)

سه راه دارید، همه همان باینری را می‌سازند:

**۱ · بگذارید CI بسازد.** workflow را دستی اجرا کنید و فایل را از Artifacts
بگیرید:

```sh
gh workflow run build.yml --ref <شعبه>
gh run list --workflow build
gh run download <run-id> -n ghost-tooth-ui-ps5
```

دو artifact ساخته می‌شود: `ghost-tooth-ui-ps5` (ELF قابل حمل + sha256) و
`ghost-tooth-ui-ps5-selfcontained` (همان ELF با `ghost-toothAPI.elf` داخلش).
روی tag های `v*` نسخه‌ی قابل حمل در Releases منتشر می‌شود.

**۲ · روی سیستم خودتان.** یک بار ابزارک‌ها را نصب کنید، بعد بیلد بگیرید:

```sh
make sdk     # دانلود و بازش کردن /opt/ps5-payload-sdk (sudo لازم دارد)
make ps5     # -> build/ghost-tooth-ui.elf
make dist    # هر دو نسخه + sha256 داخل dist/
```

`make sdk` همان بسته‌ی آماده‌ای را می‌گیرد که بقیه‌ی پیلودهای
ps5-payload-dev استفاده می‌کنند (`prospero-clang`، `lld`، sysroot و استاب‌های
`-lSce*`). توجه: کلون کردنِ خالیِ مخزن `sdk` کافی نیست، چون `make install`
آن فایل‌ها را تولید می‌کند — اگر اشتباه کنید `make ps5` همین را می‌گوید.

**۳ · فرستادن به کنسول.**

```sh
make deploy PS5_HOST=<ip-ps5>       # با prospero-deploy به پورت ۹۰۲۱
# یا با هر لودری که دارید:
cat build/ghost-tooth-ui.elf | nc <ip-ps5> 9021
```

این یک ELF معمولی است؛ مرحله‌ی `fself` یا PKG لازم ندارد. اگر `EMBED_PAYLOAD=0`
بیلد کنید، `ghost-toothAPI.elf` باید از قبل در `/data/ghost-toothAPI/` باشد؛
با `EMBED_PAYLOAD=1` (پیش‌فرض `make ps5`) اگر نبود، UI نسخه‌ی داخل خودش را آنجا
می‌گذارد.

## ساختن برای دسکتاپ

```sh
make host      # نسخه‌ی دسکتاپ + پیلود ساختگی برای تست
make test      # تست‌ها (واحد + API + سازگاری UI)
make preview   # همین UI روی :8899 با پیلود شبیه‌سازی‌شده
make check-ps5 # کامپایل همه‌ی سورس‌ها با define های کنسول، فقط با هدرها
```
